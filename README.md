# 优化方向 · 课表与打卡

一个**纯静态、零依赖**的单页应用：课表（含单双周）＋ 每日任务打卡 ＋ **健身三分化训练计划** ＋ 计划与资源清单。

**🔗 已部署（GitHub Pages）**：https://tengchengfei-cyber.github.io/orstudy/

**仓库**：https://github.com/tengchengfei-cyber/orstudy

**更新方法**：改完代码后
```bash
cd 学习站
git add -A && git commit -m "说明" && git push
```
约 1 分钟内线上自动更新（若手机还是旧版，把 `sw.js` 里的 `CACHE` 版本号 +1 再推）。

- 无框架、无构建步骤、无后端
- 打卡数据存在**你自己的设备**里（localStorage），不上传任何服务器
- 手机可用，支持「添加到主屏幕」，支持离线

## 一、马上用起来

### 方式 A · 电脑直接打开（10 秒）

双击 `index.html` 即可。缺点：file:// 下 Service Worker 不生效（离线不可用），其他功能全部正常。

### 方式 B · 手机同 WiFi 访问（推荐先这样试）

```bash
cd 学习站
python serve.py            # 默认 8000 端口
# 或指定端口：python serve.py 8123
```

终端会打印两个地址：

```
电脑打开 : http://127.0.0.1:8123/
手机打开 : http://192.168.x.x:8123/     ← 手机用这个
```

手机和电脑连**同一个 WiFi**，用手机浏览器打开第二个地址即可。

> 打不开多半是 Windows 防火墙拦了 Python —— 放行 Python，或临时关闭「专用网络」防火墙。

### 方式 C · 临时公网地址（不需要服务器）

```bash
# 用 Cloudflare 隧道，免账号，直接给你一个 https 网址
cloudflared tunnel --url http://localhost:8123
```

输出的 `https://xxx.trycloudflare.com` 就是公网地址，手机用流量也能开。
（需要先装 cloudflared；ngrok 同理也可。）

## 二、部署到云端（长期方案）

### 方案 1 · GitHub Pages（免费，最省事）

```bash
cd 学习站
git init
git add .
git commit -m "优化方向 · 课表与打卡"
git branch -M main
git remote add origin https://github.com/<你的用户名>/orstudy.git
git push -u origin main
```

然后：仓库 **Settings → Pages → Source 选 `main` / `root` → Save**。

一两分钟后访问：

```
https://<你的用户名>.github.io/orstudy/
```

### 方案 2 · Cloudflare Pages（免费，国内访问通常更快）

登录 Cloudflare Dashboard → **Workers & Pages → Create → Pages → Upload assets** → 把 `学习站` 整个文件夹拖进去 → Deploy。
得到 `https://<项目名>.pages.dev`。

### 方案 3 · 自己的云服务器 + Nginx

```bash
# 上传
scp -r 学习站 user@你的服务器:/var/www/orstudy

# Nginx 配置 /etc/nginx/conf.d/orstudy.conf
```

```nginx
server {
    listen 80;
    server_name 你的域名或IP;
    root /var/www/orstudy;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # 可选：让 sw.js 不被缓存，方便更新
    location = /sw.js {
        add_header Cache-Control "no-store";
    }
}
```

```bash
sudo nginx -t && sudo systemctl reload nginx
```

> ⚠️ **HTTPS 说明**：Service Worker（离线能力）**只在 https 或 localhost 下生效**。
> 用 IP + http 访问时页面功能完全正常，只是不能离线。想要离线，配 HTTPS
> （`certbot --nginx` 或直接走 GitHub Pages / Cloudflare Pages，它们自带 HTTPS）。

## 四、数据说明（重要）

| 项目 | 说明 |
|---|---|
| 存储位置 | 浏览器 **localStorage**，只在本机 |
| 是否上云 | **否**。没有任何数据离开你的设备 |
| 跨设备 | **不自动同步** —— 用「统计 → 数据备份与迁移」里的**导出 / 导入**（v1.4+ 也可配 GitHub / 自建后端同步） |
| 清缓存风险 | 清除浏览器数据会**丢失打卡记录**，建议定期导出备份 |
| 健身数据 | 训练计划、逐组勾选、每组重量、打卡记录一起存在 `orstudy.v1` 里，随导出备份与跨设备同步一起走 |

**迁移到手机的做法**：电脑上点「导出备份」→ 得到 JSON → 发到微信文件传输助手 → 手机上打开本站 → 「导入备份」选中该文件。

> 想要真正的跨设备自动同步，需要加一个后端（例如 Cloudflare Workers + KV 或一个几十行的 Python 服务）。当前的导出/导入是最省事且不依赖任何服务器的做法。

## 跨设备同步（v1.4+）

想让「手机勾一下、电脑立刻看到」，站内「统计 → 跨设备同步」两种方式任选。

**方式一 · GitHub 存储（推荐：零新增账号）**

1. 已建好私有仓库 `tengchengfei-cyber/orstudy-sync`（快照存 `sync/snapshot.json`）
2. 生成一个**细粒度令牌**（约 2 分钟）：
   - GitHub → 头像 → Settings → Developer settings → **Personal access tokens → Fine-grained tokens → Generate new token**
   - Token name：`orstudy-sync`
   - Expiration：1 年（到期重生成，换新令牌进站重填即可）
   - Repository access：**Only select repositories → 选 `orstudy-sync`**
   - Permissions → Repository permissions → **Contents → Read and write**
   - 生成后复制 `github_pat_…` 开头的令牌
3. 站内「统计 → 跨设备同步」→ 选 **GitHub 存储** → 填：令牌 / 用户名 `tengchengfei-cyber` / 仓库名 `orstudy-sync` / 路径 `sync/snapshot.json` → 保存并同步
4. 手机端最省事：电脑配好后「统计 → 数据备份与迁移 → 导出备份」，JSON 发到手机导入 —— **同步配置会一起带过去**

> ⚠️ 令牌等同钥匙：只填在你自己的设备上，不要截图、不要发给任何人。泄露了去 GitHub 撤销重生成即可。

**方式二 · 通用后端（Cloudflare Worker 或自建服务器）**

Worker 部署：建 Worker + 绑 KV（变量名 `SYNC`）→ 粘贴 `sync-worker.js` → 站内填地址 + 长随机密钥。
自建：`python3 sync-server.py 8124`，反代到 HTTPS 后填域名。

**机制与边界**：
- 冲突策略：**LWW（最后写入胜出）**—— 以每次保存的时间戳为准。适合单人两设备；两人同时离线编辑再同步时，后保存的一方覆盖另一方
- GitHub 方式：快照在你的**私有仓库**里，只有持令牌的人能读写；自动同步（启动拉取 + 每 2 分钟）
- 没配同步时，所有功能照常，只是不跨设备
